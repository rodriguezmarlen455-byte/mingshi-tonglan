# 《明朝那些事儿》九册通览 · 图谱站点

把当年明月《明朝那些事儿》（图文增补版·全九册，3107 页 PDF）拆成一套可检索、可复核的静态图谱：
**十六帝年表 / 读法路线图（56 章必读，附题记与整章原文）/ 皇帝谱 / 人物谱 / 六十二个战役政变节点 / 全量数据表**。

纯 HTML + CSS + JS，无构建、无依赖、无后端；`file://` 双击可开，也可直接静态托管。

## 二、数据是怎么来的（可复核）

1. **全文抽取**：pypdf 逐页抽取 3107 页 → 1 688 601 字（`D:\AI\work\full.txt`）。
2. **目次解析**：PDF 书签 189 条 → 九册 / 156 章 / 18 附录 + 每章起始页。
3. **大事记解析**：每位皇帝名下的「附录·大事记」按
   `(年号)(元|一…五十)年（公元）＋月` 正则化，得到 **210 条**带年月的条目。
   - 跨页续行：先把附录页整体拼接再去换行，避免句子被页边界切断。
   - 「以次年为XX元年（YYYY）」是跨代改元句式，先改写为「次年改元XX」，否则会被切成残句。
   - 原书错字订正：`崇祯十五年）1642）` → `（1642）`；`即皇帝们` → `即皇帝位`。
4. **人名词频**：把全书按册切成九段，统计 78 位人物的出现次数 → 每册前十名即「本册主角」；
   同时记录每人**首次出现页**。
5. **归年与时长**：全部由脚本计算，见下节。

> 区分「原书内容」与「整理内容」：附录大事记 210 条、章节标题与页码、必读章原文来自原书；
> 六十二个节点的标题与一句评述、每人的身份与一句话、九册的年份区间与主题描述为整理内容。

## 三、时间模型与不变式

- 一切时间写作 `[年, 月]`；时长 `(y2*12+m2) - (y1*12+m1)`，单位月，再折算年月。
- **十六帝 = 17 段时间**（英宗两段：正统 1435.01—1449.09、天顺 1457.01—1464.01）。
- 不变式：**同朝各段首尾相接，无缝隙、无重叠**；脚本断言 + 测试双重校验。
  总月数 **3314 = 276 年 2 个月**，与 1368.1—1644.3 完全吻合。
- **归年规则**：某年归属「该年**行用月数最多的年号**」所属皇帝，并列取后改元者。
  - 1457：景泰只占正月，天顺占十一个月 → 英宗
  - 1620：万历占 1—7 月，泰昌占 8—12 月 → 神宗
  - 1398：全年行洪武年号 → 太祖（虽崩于闰五月）
  - **1368 年之前不参与归年**：图表最上一行是灰色「元末群雄」车道，只放建国前三场决战
    （洪都 1363.04、鄱阳湖 1363.07、平江 1367.09）。

## 五、读法：把《如何阅读一本书》用在本书上（页面 02 节）

依据艾德勒、范多伦《如何阅读一本书》的**检视阅读（Inspectional Reading）**与**读历史书的规则**，
把九册书拆成一条可执行的路线，全部条目都落到具体页码。下面这张「五步」表是方法论原文；
页面上的「五步」区块已按用户要求下线（数据仍留在 `reading.steps`）：

| 步 | 做法 | 落到本书 |
|---|---|---|
| 一 | 先看书名页与序 | p8《引子》+ p3100《后记》——作者的立场全在这两处 |
| 二 | 研究目录 | 9 册 156 章，章名本身就是事件清单（已并入 02 节分册路线图） |
| 三 | 用索引替代物 | 每册末《附录·大事记》当人名/年份索引，p333《开国名将谱》当将表 |
| 四 | 只读与主题相关的篇 | 按「必读清单」挑 56 章精读 |
| 五 | 随便翻翻、只读一两段 | 每册首末各两页（章首题记与册末收束） |

- **骨架**：三条主线（权力的来源 / 制度决定谁赢 / 气节与道义）+ 四幕（创业—变局—平衡—崩塌）。
- **必读 56 章**：按册给出章名、页码范围、为什么读，以及可略读清单；
  每章**附原书题记（全 56 章都有）+ 可展开的整章原文**（共 61.8 万字 / 8802 段）。
  原文按册拆成 `assets/text/t1–t9.js`，点「原文」时才注入加载（`file://` 下同样可用，因为是 `<script>` 而非 `fetch`），
  首屏不背这 1.8 MB；单文件版则全部内联。
  段落不是猜的：原书正文行宽固定，**行宽明显短于正文行宽即为段末**，据此还原断段；
  题记保留原书的全角空格分行。
  字数由目次起止页算出，阅读速度假设 **精读 400 字/分、略读 1200 字/分**。
  结果：全书 169 万字，常规通读约 **80 小时**；按路线图 **1 + 27 + 14 ≈ 42 小时**（省 47%），
  骨架、因果与三条暗线不丢。数字由页面实时计算，不是写死的。
- **原文忠实性**：构建脚本对 8396 个段落逐字回查原书文本（只忽略空白与页标记），
  **100.00% 命中**，命中不齐会直接 assert 失败——所以「未改一字」是可复现的，不是自称。
- **读历史书的四问**（什么类型 / 作者立场与剪裁 / 与其他叙述的差异 / 他想让我接受什么），
  用本书的实际内容逐条回答，其中「剪裁」这一问用 01 节年表底部的「大事记密度」柱作证据。
- 页面上只保留 ① 骨架 ② 分册路线图 ③ 读历史书的四问；「检视阅读五步」与「主题阅读对读书」两节已按用户要求下线，
  数据仍留在 `reading.steps` / `reading.compare` 里，需要时可直接启用。

数据在 `assets/data.js` 的 `reading` 字段（`spine / acts / plan / questions`，另存已下线的 `steps / compare`），
必读章按**章名**匹配目次，匹配失败会让构建脚本直接报错退出，避免页码错位。

## 六、图怎么读

- **01 帝系年表**（含全量数据表）：一行一帝，横轴 1352—1644（原生像素排版：默认 7.2 px/年，可 ± 调密度、「适配」看全图；按住拖动平移，Shift+滚轮横移；左侧标签列固定不随拖动移动；每 1/5/10 年三级刻线，6.5 px/年 以上年份标签加密到每 5 年）。浅红长条 = 在位区间（到月），条内年号；
  条上方的彩色小刻 = 大事（战 / 政 / 制 / 外 / 文 / 灾），颜色即类别；
  条右端数字 = 在位时长；顶部九条色带 = 九册各自覆盖的年份；底部褐色柱 = 该年附录大事记条数。
  点任意行 / 任意年份 → 右栏显示该年详情（当年节点 + 当年原书附录原文 + 前后三年 + 在位者）。
- **04 人物谱**：次数是全书提及次数，条形同比例尺；按册筛选 + 检索。
- **05 战役节点**：62 条按类别筛选。
- **数据表**（已并入 01 节末尾）：十六帝 + 210 条附录大事记，可检索、可导出。
- **导出**：页面右上与 09 节均可导出 CSV / JSON（Excel 直开，UTF-8 BOM）。

## 七、发布

### 局域网

```bash
node serve.js 8080
```
其它机器访问 `http://<本机IP>:8080/`。Windows 防火墙默认阻止入站，需**管理员**执行：
```
netsh advfirewall firewall add rule name="site-8080" dir=in action=allow protocol=TCP localport=8080
```

### 永久网址（Netlify API）

```bash
node zipit.js . ming.zip                               # 必须用正斜杠打包
node deploy-netlify.js <Personal Access Token> ming-tonglan
```
两个坑（已写进脚本）：zip 路径反斜杠会让解压后目录层级丢失；
新站默认 `sso_login=true` 会把访客打到 401，脚本会 `PATCH` 关掉。
令牌用完请到 <https://app.netlify.com/user/applications> 撤销（已部署站点不受影响）。

## 八、已知边界

- 页码一律指该 PDF 的页序（1—3107），不是纸书页码。
- 附录大事记的年份以原书为准，未做史料层面的重新考订；个别条目原文把多件事并在一句里，
  解析时保留在同一行，读起来仍是原句。
- 人物生卒中「不详」者为史无明载；提及次数含姓名与常见别称，未做同名消歧（如「汪直」既是
  成化朝太监也是嘉靖朝海商，两者合并计数，故卡片里用身份区分）。
